# Machine Learning Projects

Welcome to my Machine Learning repository!

This repository contains a collection of practical Machine Learning projects developed using Python. The projects explore fundamental Machine Learning concepts and demonstrate how different algorithms can be applied to real-world datasets and problems.

## Technologies & Libraries

- **Python** – Programming language
- **NumPy** – Numerical computing
- **Pandas** – Data manipulation and analysis
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical data visualization
- **Scikit-learn** – Machine Learning algorithms and model evaluation
- **Jupyter Notebook** – Interactive development and experimentation

## Projects

The repository includes projects covering different Machine Learning techniques:

- **Linear Regression:** Building predictive models and analyzing relationships between variables.
- **Logistic Regression:** Applying classification techniques to predict categorical outcomes.
- **K-Means Clustering:** Discovering patterns and grouping similar data points.
- **Classification:** Training models to classify data into different categories.
- **Handwritten Digit Recognition:** Working with the Scikit-learn Digits dataset to recognize handwritten numbers.
- **CO₂ Emissions Prediction:** Using vehicle specifications and fuel consumption data to predict CO₂ emissions.
- **Diabetes Prediction:** Exploring classification techniques using a diabetes dataset.
- **Image Processing:** Learning practical image manipulation and numerical image representation.

## Learning Objectives

Through these projects, I aim to:

- Understand fundamental Machine Learning algorithms.
- Practice data preprocessing and exploratory data analysis.
- Train and evaluate predictive models.
- Understand classification, regression, and clustering techniques.
- Improve Python programming and problem-solving skills.
- Build practical experience with real-world datasets.

## Repository Structure

Each project is organized in its own Jupyter Notebook (`.ipynb`), including code, explanations, and visualizations.
