# Diabetes Prediction Using Logistic Regression (392 Records)

## 📌 Description
This project uses Machine Learning to predict diabetes based on medical and health-related data.

A Logistic Regression model is trained to classify individuals into two categories: diabetic and non-diabetic.

## 📊 Dataset
The dataset contains 392 records and 8 input features.

Features:
- Pregnancies
- Glucose
- BloodPressure
- SkinThickness
- Insulin
- BMI
- DiabetesPedigreeFunction
- Age

Target Variable:
- 0: Non-diabetic
- 1: Diabetic

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn

## ⚙️ Workflow
1. Importing Python libraries.
2. Loading the dataset.
3. Exploring and analyzing data.
4. Separating features (X) and target (y).
5. Splitting data into training and testing sets.
6. Building a Logistic Regression model.
7. Training the model.
8. Predicting outcomes using test data.
9. Comparing predictions with actual values.
10. Testing the model with new sample data.

## 🤖 Algorithm
Logistic Regression (Binary Classification)

## 🎯 Objective
The goal is to practice supervised machine learning, classification, model training, and prediction using Python.

## ⚠️ Disclaimer
This project is for educational purposes only and is not intended for medical diagnosis.

# Diabetes Prediction Using Logistic Regression(768 Records)

## 📌 Description
This project focuses on predicting diabetes using a Machine Learning classification algorithm.

The model uses medical information to predict whether an individual is diabetic or non-diabetic.

## 📊 Dataset
The dataset contains 768 records and 8 input features.

Features:
- Pregnancies
- Glucose
- BloodPressure
- SkinThickness
- Insulin
- BMI
- DiabetesPedigreeFunction
- Age

Target Variable:
- 0: Non-diabetic
- 1: Diabetic

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn

## ⚙️ Workflow
1. Importing the required libraries.
2. Loading the dataset using Pandas.
3. Exploring the dataset using `head()` and `describe()`.
4. Separating input features (X) and target variable (y).
5. Splitting data into training and testing sets (80/20).
6. Creating a Logistic Regression model.
7. Training the model using training data.
8. Predicting outcomes on test data.
9. Comparing predicted values with actual results.
10. Making predictions using new sample data.

Logistic Regression

Logistic Regression is a supervised machine learning algorithm used for binary classification problems.
