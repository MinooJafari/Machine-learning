# Multiple Linear Regression

## Project Overview
This project demonstrates the implementation of **Multiple Linear Regression**, a supervised machine learning algorithm used to predict a continuous target variable based on multiple independent features.

The project is developed using Python in Jupyter Notebook and focuses on understanding how multiple input variables can be used to build a predictive model.

## Mathematical Concept

Multiple Linear Regression models the relationship between one dependent variable and two or more independent variables.

The general equation is:

\[
Y = \beta_0 + \beta_1X_1 + \beta_2X_2 + \cdots + \beta_nX_n + \epsilon
\]

Where:
- \(Y\): Dependent variable (target)
- \(X_1, X_2, ..., X_n\): Independent variables (features)
- \(\beta_0\): Intercept
- \(\beta_1, ..., \beta_n\): Regression coefficients
- \(\epsilon\): Error term
